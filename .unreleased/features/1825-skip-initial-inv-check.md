`check` no longer checks an invariant in state 0 if the invariant is a conjunct of the `--init` predicate. This is what happens when checking an inductive invariant, e.g., with `--init=IndInit --inv=IndInv` and `IndInit == TypeOK /\ IndInv`: the initial states satisfy the invariant by construction, so the check only costs time. Invariants are compared conjunct by conjunct, so the conjuncts that do not follow from `--init` are still checked in state 0, see #1825.
